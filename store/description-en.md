# Nonogram — Store Submission Materials

## Short description (CrazyGames / GameDistribution / itch.io)

Fill cells using the row and column number clues to reveal the hidden
picture. Every puzzle is generated and verified to have exactly one
solution. Three sizes, ink-and-paper style, free to play.

## Details

- Genre: Puzzle / Logic / Casual
- Controls: Mouse / Touch. Tap or left-click to fill (drag to paint),
  right-click or Mark mode to draw ×. Keys: U undo, M mark mode, H check.
- Features: 5×5 / 10×10 / 15×15 puzzles with guaranteed-unique solutions,
  error check (2 per puzzle), over-count warnings, undo, mark mode, timer
  with best times per size, procedural graphics & sounds, single-file HTML5
  (no external assets), works offline once loaded.
- Tech: Vanilla JavaScript, Canvas, WebAudio. No frameworks, no tracking.
